# 科研能力第一课：缝补实验法

> 适用对象：能借助 AI 跑通代码，但"完全看不懂"的研一学生。
> 核心判断：**你现在缺的不是写代码的能力，是"读代码 + 判断数字真假"的能力。**

---

## 0. 三条路的权重（先定这个，避免乱学）

| 路 | 判据 | 权重 |
|---|---|---|
| **(c) 缝补实验** | 能不能跑完一个完整闭环 | **70%** |
| **(a) 补基础** | 能不能**解释你看到的数字** | 20% |
| **(b) 手撕代码** | 能不能**不再害怕打开文件** | 10% |

**关键**：(b) 的价值被普遍高估。手撕的目的是解除恐惧，不是复现论文。所以只撕到"能看懂骨架"为止。

---

## 1. 手撕的正确规模：3 个模型，250 行，3–5 天

**顺序很重要：不要从 SASRec 开始，从 GRU4Rec 开始。**

| 顺序 | 模型 | 行数（你的仓库） | 为什么 |
|---|---|---|---|
| 1 | **GRU4Rec** | ~70 | 无 attention、无 mask，但**包含序列推荐全部骨架** |
| 2 | **SASRec** | ~63 | 只是把 GRU 编码器换成 attention 编码器 |
| 3 | **BSARec** | ~104 | 再在中间插一个频域分支 |

**序列推荐的骨架（GRU4Rec 里全有）**：
```
item embedding → 序列编码 → 取最后位置 h → 与 item 矩阵打分 → 
采样负样本 → loss → 全排序评估
```
手写一遍这 70 行，你就掌握了"序列推荐是什么"。剩下两个模型都是在这骨架上换零件。

**验收**：合上文件，能把这个骨架画出来并解释每一环。**到此为止。**

---

## 2. 读代码三步法（不是从头读）

### 步 1：追一个张量的形状（10 分钟）
在 `forward` 里 print 每层的 shape，看 `[batch, seq_len, hidden]` 怎么变。**比读一小时代码有效。**

### 步 2：改一行，看输出怎么变
把 `alpha` 从 0.7 改成 0.0，看 loss 曲线、看输出。**"改一行看变化"是零基础读代码最有效的手段**——因为你会立刻知道这一行控制什么。

### 步 3：让 AI 逐行讲，但你只记 4 个问题
1. 输入是什么形状？最后一层怎么变成推荐分数？
2. 哪个参数控制什么？（`alpha`、`c`、`sqrt_beta` 各管什么）
3. 某个参数取极端值，会退化成什么模型？
4. 这个模块有没有处理 padding / mask？

**判据**：合上文件能回答这 4 个问题。**别往深处读。**

## 3. 缝补实验的五步闭环（本文档的核心）

### ❌ 错误示范（抽卡式）
> AI 说"试试加个 gate" → 改 → 跑 → 涨了 0.001 → 高兴 → 下一篇

问题：没有预测、没有噪声判据、没有归因 → **什么都没积累**。

### ✅ 正确闭环

| 步 | 做什么 | 不能省的理由 |
|---|---|---|
| **1. 先写预测** | "我认为 X 会让 Y 涨/跌，因为 Z" | 没预测，结果是什么都能事后编故事 |
| **2. 最小改动** | 只改一处（一行～十行） | 改三处，涨了也不知道哪处起作用 |
| **3. 跑 + 过噪声地板** | Δ > 3-seed 标准差才叫有效 | 没有 σ，80% 的"提升"是噪声 |
| **4. 归因**（无效时最重要） | 想法错？实现错？还是数据集不敏感？ | 三种归因指向三个完全不同的下一步 |
| **5. 记一行结论** | "假设错了，原因是 X" | 攒够 20 行 = 你自己的领域直觉 |

**第 1 步和第 4 步是能力的本体，且都不需要会写代码。**

## 4. 修正师兄的方法："换假设，不换论文"

原方法：复现 → 选最快的数据集 → AI 给方向 → 改几次无效就**换一篇**。

**问题在最后两个字**：换一篇 = 每次从零熟悉新仓库，学到的是"在陌生代码里找参数"，不是"判断想法对不对"。

**改成**：在同一篇论文上做 5 个缝补实验，每个都做归因。

| | 横向换论文 | 纵向换假设 |
|---|---|---|
| 5 次之后你得到 | 5 个半懂的仓库 | 1 个能辩论的模型 + 5 条结论 |
| 面试可讲 | "我跑过很多论文" | "我在这篇上试过 5 个方向，其中 4 个失败，原因是……" |

## 5. 第一个缝补实验（今天就定，1 天 GPU）

**对象**：BSARec 仓库，Beauty 数据集

```
假设：--alpha 0（= SASRec + CE loss，架构完全相同）的 HR@20
     会落在 BSARec 的 95%–100% 区间，但追不平。
依据：论文 Sec. Relation to Previous Models 自己承认
     "α=0 时退化为 SASRec，但两者 loss 不同（BSARec 用 CE，SASRec 用 BCE）"
     → 这句话等于把核心结论悬空了。
改动：一行参数（--alpha 0）
判据：Beauty 先跑 3 个 seed 得 σ；Δ > σ 才算有效
归因：若追平（Δ<σ）→ 频域无独立贡献；
     若差 >5% → 频域有贡献，值得继续挖
```

**一个实验拿三样东西**：① 一次完整闭环；② 论文 D1 的核心实验；③ 能跟导师讲的故事。

## 7. 明确不做

| ❌ | 为什么 |
|---|---|
| 泛读 20 篇文献 | 你还没有判断好坏的能力，泛读 = 浪费时间。**只读正在改的模块相关的 3 篇，带具体问题去读** |
| 补线代/概率论教材 | 你不需要推导，需要的是"为什么低频=长期兴趣"这种一句话解释 |
| 手撕 8 个经典模型 | 3 个（GRU4Rec → SASRec → BSARec）250 行足够 |
| 在没跑 3 seed 的情况下下结论 | 这是最容易浪费一个月的地方 |
| 换论文代替换假设 | 见第 4 节 |
