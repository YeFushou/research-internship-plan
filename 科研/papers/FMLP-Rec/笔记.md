# FMLP-Rec 论文阅读笔记

**论文名称：** Filter-enhanced MLP is All You Need for Sequential Recommendation

**作者：** Kun Zhou、Hui Yu、Wayne Xin Zhao、Ji-Rong Wen

**发表会议：** WWW 2022

**研究方向：** 序列推荐（Sequential Recommendation）

---

# 一、论文研究背景与核心问题

## 1.1 研究任务：序列推荐

序列推荐的目标是根据用户过去按时间顺序产生的物品交互记录，预测用户下一步可能交互的物品。

例如：

用户历史行为：

手机 → 手机壳 → 耳机 → 充电器

模型需要根据这段历史行为，预测用户接下来可能感兴趣的物品。

与普通推荐不同，序列推荐不仅需要考虑用户交互过哪些物品，还需要考虑这些物品之间的先后顺序，以及用户兴趣随时间发生的变化。

## 1.2 现有模型存在的问题

论文介绍了几类典型的序列推荐模型：

- RNN：通过循环神经网络学习用户行为序列，例如 GRU4Rec。
- CNN：通过卷积操作提取序列中的局部模式，例如 Caser。
- Transformer：通过多头自注意力机制学习物品之间的关系，例如 SASRec、BERT4Rec。

作者认为现有模型存在两个主要问题：

**问题一：模型结构相对复杂。**

Transformer 通过堆叠多头自注意力模块建模序列，涉及较多参数和计算开销。

**问题二：用户行为数据中存在噪声。**

真实平台记录的用户行为可能包含偶然点击、异常交互等噪声。深度推荐模型容易拟合这些数据中的无效信息，进而产生过拟合。

作者尤其关注自注意力模型：它在建模时关注序列中的物品关系，因此噪声可能影响模型对行为关系的学习。

## 1.3 作者的核心研究思路

作者从数字信号处理领域借鉴滤波思想：

1. 将用户行为序列的嵌入表示转换到频域。
2. 使用滤波器调整不同频率成分。
3. 将调整后的表示转换回原来的序列空间。
4. 通过这种方式减弱噪声的潜在影响。
5. 在此基础上移除 Transformer 中复杂的自注意力模块，使用 MLP 构建更轻量的模型。

论文最终提出 FMLP-Rec：一个结合可学习滤波器的全 MLP 序列推荐模型。

**核心思想：利用频域滤波增强序列表示，同时使用相对简单的 MLP 结构完成序列建模。**

# 二、Preliminaries（预备知识）

本章主要介绍序列推荐任务的定义，以及论文所使用的傅里叶变换基础。

## 2.1 序列推荐问题定义

假设用户有一段按照时间顺序排列的交互记录：

i₁、i₂、i₃、……、iₙ

其中：

- i 表示一个物品。
- n 表示用户历史交互序列的长度。
- iₜ 表示用户在第 t 个位置交互的物品。

模型根据用户前面已经发生的交互行为，预测下一个物品 iₙ₊₁。

论文研究的是隐式反馈（Implicit Feedback）场景，即主要利用用户是否发生过交互，而不是用户明确给出的评分。

**本质任务：根据用户已有的物品交互序列，预测下一个可能交互的物品。**

## 2.2 Fourier Transform（傅里叶变换）

### 2.2.1 离散傅里叶变换（DFT）

离散傅里叶变换可以将一段序列从时域转换到频域。

两种表示方式的区别：

- 时域：从序列位置的角度观察数据，关注不同位置上的特征值。
- 频域：从变化频率的角度观察数据，分析序列中不同频率成分。

频域表示能够帮助我们观察序列中不同变化速度的成分。

需要理解的是，转换到频域并不是改变用户的行为记录，而是改变观察和处理同一份数据的方式。

### 2.2.2 逆离散傅里叶变换（IDFT）

傅里叶变换具有可逆性。

通过逆离散傅里叶变换，可以将频域表示还原为原来的时域表示。

因此，模型可以先在频域中调整不同频率成分，再将结果转换回序列表示。

### 2.2.3 快速傅里叶变换（FFT）

快速傅里叶变换是计算离散傅里叶变换的高效算法。

论文指出，长度为 N 的序列，其 FFT 的时间复杂度为 O(N log N)。

逆变换则使用 IFFT 完成。

### 2.2.4 傅里叶变换在本文中的作用

作者希望利用频域分析和滤波算法，减轻用户行为序列中噪声特征的影响。

传统低通滤波器能够削弱高频成分。作者据此进一步研究不同滤波算法能否改善序列推荐模型的效果。

**本章需要掌握：**

- FFT：从时域转换到频域。
- IFFT：从频域还原到时域。
- 滤波：在频域中调整不同频率成分。
- FFT 的计算复杂度为 O(n log n)。

不需要深入掌握傅里叶变换的数学推导。

# 三、Empirical Analysis with Filtering Algorithms for Recommendation（滤波算法在推荐中的实验分析）

本章是论文提出 FMLP-Rec 之前的实验探索，主要验证两个问题：

1. 滤波算法能否改善已有序列推荐模型的性能？
2. 滤波算法与全 MLP 结构结合后，能否取得良好的推荐效果？

## 3.1 Analysis Setup（实验设置）

### 3.1.1 实验数据集

作者选择 Amazon Beauty 和 Sports 两个数据集进行实验。

### 3.1.2 对比模型

作者选择 GRU4Rec 和 SASRec：

| 模型 | 序列编码方式 |
|---|---|
| GRU4Rec | RNN |
| SASRec | Transformer / 自注意力 |

两种模型都包含三个基本部分：

- Embedding Layer：将物品 ID 转换为向量表示。
- Sequence Encoder Layer：学习用户行为序列特征。
- Prediction Layer：根据序列表示预测下一物品。

### 3.1.3 实验方法

作者在 Embedding Layer 与 Sequence Encoder Layer 之间添加一个无可学习参数的滤波层，其他模型组件保持不变。

具体处理流程：

**Embedding Matrix → FFT → Filtering Algorithm → IFFT → Sequence Encoder**

作者选择三种经典滤波算法：

| 滤波器 | 主要作用 | 处理方式 |
|---|---|---|
| HPF（高通滤波器） | 保留高频，削弱低频 | 将低频部分置零 |
| LPF（低通滤波器） | 保留低频，削弱高频 | 将高频部分置零 |
| BSF（带阻滤波器） | 保留低频和高频，削弱中频 | 将中频部分置零 |

### 3.2 Results and Findings（实验结果与发现）

#### 3.2.1 滤波算法对现有模型的影响

作者报告了 GRU4Rec 和 SASRec 加入不同滤波器后的实验结果。

**表 1：不同滤波算法对 GRU4Rec 和 SASRec 的影响**

| 模型 | 滤波方式 | Beauty HR@10 | Beauty NDCG@10 | Sports HR@10 | Sports NDCG@10 |
|---|---|---:|---:|---:|---:|
| GRU4Rec | 原始 | 0.4106 | 0.2584 | 0.4299 | 0.2527 |
| GRU4Rec | HPF | 0.3828 | 0.2228 | 0.3654 | 0.2063 |
| GRU4Rec | LPF | 0.4351 | **0.2689** | **0.4481** | **0.2578** |
| GRU4Rec | BSF | **0.4372** | 0.2658 | 0.4432 | 0.2563 |
| SASRec | 原始 | 0.4696 | 0.3156 | 0.4622 | 0.2869 |
| SASRec | HPF | 0.4544 | 0.3037 | 0.4530 | 0.2785 |
| SASRec | LPF | 0.4941 | 0.3320 | 0.5040 | 0.3138 |
| SASRec | BSF | **0.5011** | **0.3334** | **0.5115** | **0.3172** |

注：加粗表示同一模型、同一数据集和同一评价指标下的最高结果。

作者主要得出以下发现：

1. 在多数情况下，LPF 和 BSF 能够改善原有模型的推荐性能，特别是在 SASRec 上。
2. 对 GRU4Rec 而言，LPF 的整体表现较好；对 SASRec 而言，BSF 表现最好。
3. HPF 在大多数情况下会导致推荐性能下降。
4. 物品嵌入矩阵可能包含影响模型性能的噪声。
5. 对嵌入表示进行适当滤波可能有助于减轻噪声影响。
6. 低频信息对序列推荐似乎更加重要，但不同模型适合的滤波方式可能不同。

**重要理解：**

高频不完全等于噪声，低频也不完全等于有效信息。实验只是说明不同频率成分对推荐效果有不同影响，并且这种影响与模型有关。

#### 3.2.2 滤波算法对全 MLP 模型的影响

在第一组实验中，作者发现滤波算法可以改善 GRU4Rec 和 SASRec 的性能。

于是进一步提出一个问题：

如果去掉 Transformer 中复杂的自注意力模块，只保留 MLP，再加入滤波层，模型能否继续保持良好的推荐效果？

作者以 SASRec 为基础进行修改：

- 移除 Transformer 序列编码器中的多头自注意力模块。
- 在 Embedding Layer 之后添加滤波层。
- 继续使用 HPF、LPF 和 BSF。
- 其他组件保持不变。

实验结果表明：

- 移除自注意力后，大多数全 MLP 变体仍然表现良好。
- 使用 LPF 的全 MLP 变体甚至明显超过原始 SASRec。
- 滤波与 MLP 结合具有较好的研究潜力。
- 简化模型结构有助于降低模型复杂度以及过拟合风险。

**第三章的核心结论：**

固定滤波器能够改善部分已有序列推荐模型的性能；即使去掉复杂的自注意力模块，结合滤波的全 MLP 架构仍可能取得较好的推荐效果。

这为作者提出 FMLP-Rec 提供了实验依据。

# 四、Method（模型方法）

## 4.1 FMLP-Rec：结合可学习滤波器的全 MLP 序列推荐模型

### 4.1.1 模型设计动机

第三章已经证明，使用固定滤波算法能够改善部分模型的推荐性能。

但是，传统滤波算法通常需要研究人员根据经验选择滤波方式和阈值。

例如：

- 应该选择 HPF、LPF 还是 BSF？
- 应该削弱哪些频率？
- 不同数据集是否需要不同的滤波方式？

这些问题都需要人工设计。

因此，作者提出可学习滤波器，让模型在训练过程中自动学习合适的频率调整方式，而不是提前固定滤波规则。

### 4.1.2 整体模型结构

FMLP-Rec 的整体结构与 Transformer 类似，采用多层神经网络模块进行堆叠。

主要包括：

1. Embedding Layer
2. Learnable Filter-enhanced Blocks
3. Prediction Layer

核心变化是：

**使用可学习滤波模块替代 Transformer 中的多头自注意力模块，并通过 MLP 进一步提取特征。**

### 4.1.3 Embedding Layer（嵌入层）

首先，模型维护一个物品嵌入矩阵。

它的作用是将高维的物品 ID 表示转换为低维稠密向量。

给定用户的物品交互序列，模型通过查表操作获得物品嵌入矩阵。

接着，作者加入可学习的位置编码矩阵，用于提供物品在序列中的位置信息。

物品嵌入与位置编码相加后，经过 LayerNorm 和 Dropout，得到最终的序列表示。

**本模块作用：将用户的物品交互记录转换成包含物品信息和位置信息的向量序列。**

### 4.1.4 Learnable Filter-enhanced Blocks（可学习滤波增强模块）

这是 FMLP-Rec 的核心组成部分。

每个滤波增强模块包含两个子模块：

- Filter Layer
- Point-wise Feed-forward Network

#### A. Filter Layer（滤波层）

滤波层主要完成频域信息调整。

处理流程：

1. FFT：将输入序列表示转换到频域。
2. Learnable Filter：通过可学习滤波器调整不同频率成分。
3. IFFT：将调整后的频域表示转换回时域。
4. Skip Connection：保留原始输入信息，并与滤波结果相加。
5. LayerNorm：对结果进行归一化。

其中，可学习滤波器是这一部分最关键的设计。

它与第三章中的固定滤波器不同：

- 固定滤波器：人工规定保留或削弱哪些频率成分。
- 可学习滤波器：通过训练自动调整不同频率成分的强弱。

可学习滤波器的参数通过 SGD 优化，根据推荐任务的训练损失不断更新。

它并不是人工指定某个频率一定属于噪声，而是学习哪些频率信息更有助于完成推荐任务。

**本模块作用：在频域中自适应调整序列表示，减轻噪声的潜在影响，同时保留有用的序列特征。**

#### B. Point-wise Feed-forward Network（逐位置前馈网络）

滤波层主要完成频率成分的调整，而前馈网络则进一步学习非线性特征。

论文使用：

- MLP：进行特征变换。
- ReLU：引入非线性能力。
- Skip Connection：保留输入信息。
- LayerNorm：稳定训练过程。

**本模块作用：在滤波处理之后，进一步提取和变换序列特征。**

### 4.1.5 Prediction Layer（预测层）

经过多层滤波增强模块后，模型得到最终的用户序列表示。

预测层将用户在当前时刻的序列表示与候选物品的嵌入向量进行匹配，计算用户对候选物品的偏好分数。

分数越高，表示模型认为用户下一步交互该物品的可能性越大。

训练时，作者采用 Pairwise Rank Loss（成对排序损失）。

具体而言：

- 正样本：用户真实交互的下一个物品。
- 负样本：随机采样的物品。
- 优化目标：让真实物品的预测分数高于负样本物品。

这里的负样本并不意味着用户明确讨厌该物品，只是训练时用于排序比较的采样物品。

**本模块作用：根据最终序列表示计算候选物品的偏好分数，并通过排序损失优化模型。**

## 4.2 Theoretical Analysis with Filter Layers（滤波层的理论分析）

这一节主要证明一个重要结论：

**频域中的逐元素乘法，等价于时域中的循环卷积。**

### 4.2.1 可学习滤波器与循环卷积的关系

FMLP-Rec 的滤波层先使用 FFT 将输入转换到频域，再与可学习滤波器进行逐元素相乘，最后通过 IFFT 转换回时域。

根据卷积定理，作者证明：

频域中的逐元素乘法，等价于时域中的循环卷积。

这说明滤波层不仅能够调整频率成分，还能够通过循环卷积提取序列特征。

### 4.2.2 什么是循环卷积？

普通卷积通常受到卷积核大小的限制，主要利用一定范围内的局部信息。

循环卷积采用周期性边界处理。

当计算位置访问序列末尾之外的位置时，会通过循环索引回到序列开头。

例如：

A → B → C → D

在循环边界处理中，D 后面可以访问到 A。

这是一种卷积计算方式，并不意味着用户真实行为一定按照周期重复。

### 4.2.3 循环卷积的特点

作者强调了两个特点：

**第一，具有全序列感受野。**

滤波层等价于使用覆盖整个序列长度的循环卷积，因此可以利用整条序列的信息，而不仅仅局限于附近的几个位置。

**第二，有助于捕获周期性模式。**

用户行为可能表现出一定的重复规律。循环卷积能够利用这种周期性边界结构提取序列特征。

**本节核心结论：**

FMLP-Rec 的可学习滤波器不只是一个简单的降噪模块，它还能够实现全序列范围内的特征建模。

数学推导本身不需要逐行记忆，重点掌握频域乘法与时域循环卷积之间的等价关系。

## 4.3 Discussion（讨论）

### 4.3.1 与 Transformer 序列推荐模型的比较

Transformer 模型（例如 SASRec 和 BERT4Rec）通常通过堆叠多头自注意力模块学习序列表示。

自注意力主要用于学习物品与物品之间的关联关系。

相比之下，FMLP-Rec：

- 移除了多头自注意力结构。
- 使用 MLP 作为主要特征学习模块。
- 加入可学习滤波层。
- 通过滤波层实现全序列范围内的特征建模。

论文认为，这种设计能够减少模型的时间和空间开销。

此外，循环卷积能够覆盖整个序列，因此 FMLP-Rec 可以在保持与自注意力机制相同感受野的同时，减少涉及的参数数量。

### 4.3.2 时间复杂度与感受野分析

作者选择 Caser、SASRec 和 FMLP-Rec 进行比较。

**表 2：模型的时间复杂度与感受野**

| 模型 | 每层时间复杂度 | 感受野 |
|---|---|---|
| Caser | O(kn) | k |
| SASRec | O(n²) | n |
| FMLP-Rec | O(n log n) | n |

其中：

- n：序列长度。
- k：Caser 中的卷积核大小。

**Caser：**

通过卷积操作捕获局部序列模式，感受野受到卷积核大小限制。若希望覆盖更长的序列，通常需要扩大卷积核。

**SASRec：**

通过自注意力计算物品之间的关联，需要计算不同物品对之间的相似度，因此时间复杂度为 O(n²)，感受野为 n。

**FMLP-Rec：**

主要计算包含 FFT、IFFT 和逐位置前馈网络。

FFT 和 IFFT 的复杂度为 O(n log n)，前馈网络关于序列长度的复杂度为 O(n)，因此整体时间复杂度为 O(n log n)。

由于滤波层等价于覆盖整个序列的循环卷积，其感受野为 n。

### 4.3.3 本节结论

与 Caser 相比，FMLP-Rec 能够获得更大的序列感受野。

与 SASRec 相比，FMLP-Rec 保持了相同的全序列感受野，同时将理论时间复杂度从 O(n²) 降低到 O(n log n)。

需要注意：理论复杂度不等于所有实际运行环境下的速度比较，实际效率还受到序列长度、硬件和实现方式等因素影响。

## 七、个人阅读理解与后续思考

**目前对论文的理解：**

FMLP-Rec 并不是简单地将 Transformer 替换成 MLP，而是利用频域滤波机制补充序列建模能力。固定滤波实验验证了滤波思想的有效性，随后作者引入可学习滤波器，使模型能够根据推荐任务自动调整不同频率成分。

**后续值得关注的问题：**

1. 可学习滤波器在不同数据集上学到的频率调整规律是否存在明显差异？
2. 滤波模块对模型性能的提升究竟来自噪声抑制，还是来自全序列特征建模？
3. FMLP-Rec 与 SASRec、BSARec 等模型相比，在模型结构和频域建模机制上有哪些区别？
4. 当移除滤波层或 FFN 时，模型性能会发生什么变化？

这些问题可以作为后续阅读实验章节、开展消融实验和模型对比时的思考方向。
